# Desktop Application Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for bounded
> delegated work; keep shared-file changes owned by one worker. Steps use checkboxes.

**Goal:** Launch the current Stegloc UI as a Windows desktop executable.

**Architecture:** pywebview displays the prebuilt React application served by the
existing FastAPI factory on a private loopback port. PyInstaller bundles the
launcher, Python runtime and frontend assets as a windowed folder distribution.

**Tech Stack:** Python, FastAPI/Uvicorn, React/Vite, pywebview, PyInstaller.

## Chunk 1: Desktop launch and distribution

### Task 1: Desktop lifecycle and API protection

Files: `backend/desktop.py`, `desktop.py`, `backend/app/main.py`,
`tests/test_desktop.py`, `tests/test_app.py`.

- [x] Add regression checks for startup and shutdown with a real loopback server,
  failure cleanup, active-request shutdown, missing assets, and desktop
  authentication/bootstrap cookies.
- [x] Implement startup on a retained socket, a bounded readiness wait, visible
  startup errors and cleanup in `finally`. Keep webview on the main thread. Set a
  two-second graceful shutdown timeout and a five-second daemon thread join limit.
- [x] Add optional desktop-only cookie authentication and write-origin checks to
  `create_app`; keep the existing browser mode unchanged.
- [x] Run `python -m pytest tests/test_desktop.py tests/test_app.py -q`; expect no
  failures and confirm sockets close after both normal and exceptional exit.

### Task 2: Packaging and instructions

Files: `Stegloc.spec`, `scripts/build-desktop.ps1`, `pyproject.toml`, `.gitignore`,
`README.md`, `frontend/src/api.ts`, `frontend/src/pages/KeysPage.tsx`.

- [x] Add desktop/build dependency groups, a spec collecting frontend assets in
  `frontend/dist`, and a checked PowerShell script running the frontend build and

- [x] Ignore build output and update the README with source launch, build steps,

- [x] Run `npm run build` in `frontend`; expect successful typechecking and bundle.

### Task 3: Verification and review

- [x] Run `python -m pytest -q`; record the complete suite result.
- [x] Execute the PowerShell build script; inspect the frozen distribution.
- [x] Smoke-test the packaged app and file-save paths when desktop automation is

- [x] Review the final diff for lifecycle leaks, bundled assets, security and
  unnecessary scope; fix findings before delivery.
